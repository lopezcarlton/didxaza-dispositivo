# Experimentos de texto real

Este subárbol contiene probes experimentales no autoritativos para observar el comportamiento del dispositivo sobre texto nuevo.

Reglas:

- el texto de entrada se conserva exactamente antes de cualquier normalización;
- una salida del Analyzer no constituye corrección, validación lingüística ni fuente de reglas;
- los experimentos no usan COR001 como benchmark;
- si una segunda pasada normaliza puntuación u ortografía, debe registrarse como una condición experimental separada;
- un fallo observado puede motivar investigación o cambios técnicos posteriores, pero no se corrige el repositorio por anticipado.
