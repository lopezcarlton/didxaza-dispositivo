# didxaza-dispositivo

Implementación técnica derivada del Sistema de Conocimiento de Voces de las Nubes.

Este repositorio contiene Analyzer, Corrector, Tutor, Generator, runtime, tests, estados técnicos y artefactos de reproducibilidad. No constituye autoridad lingüística, pedagógica ni comunitaria.

Fuente canónica de conocimiento: `lopezcarlton/vocesdelasnubes`.
